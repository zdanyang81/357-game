# 357 · 酒吧骰子游戏

酒吧里经典的 3-5-7 骰子博弈，纯前端网页，浏览器直接打开即玩，无需安装依赖。

## 玩法规则

- 棋盘上排列三排骰子：第一排 **3** 颗、第二排 **5** 颗、第三排 **7** 颗。
- 双方轮流行动，每回合**只能从某一排**拿走任意数量（至少 1 颗）的骰子。
- **拿到最后一颗骰子的人输**，另一方获胜（misère 规则，酒吧常见玩法）。

> 提示：这是一个有必胜策略的公平游戏。先手有必胜走法（第一手从第 1 排拿 1 颗）；
> 想挑战的话可以让人机 AI 先手，或者自己研究「异或和（nim-sum）」策略。

## 玩法模式

| 模式 | 说明 |
| --- | --- |
| 👥 双人对战 | 两人共用一台设备轮流拿 |
| 🤖 人机对战 | 和电脑玩，电脑按最优策略走（并模拟思考延迟） |

## 如何打开

直接用浏览器打开 `index.html` 即可，无需服务器、无需安装任何依赖：

```bash
open index.html
```

手机/平板想把页面放桌上玩，也可以用任意静态服务器：

```bash
python3 -m http.server 8000
# 然后浏览器访问 http://localhost:8000
```

## 操作方式

1. 点击一排中某一颗骰子，会选中该排**前 N 颗**（连选，N 即你想拿走的数量）。
2. 点「确认拿取」落子，或点「取消」重新选择。
3. 右侧/下方走子记录会列出每一手的详情；对局结束弹出胜负横幅，可「再来一局」。

## 项目结构

```
357-game/
├── index.html       # 页面结构
├── css/style.css    # 暗色酒吧风主题、骰子样式与动画
└── js/
    ├── game.js      # 核心规则：状态、走子校验、misère 胜负判定（纯逻辑，无 DOM）
    ├── ai.js        # AI：动态规划预计算全部局面胜负表，选最优步
    └── ui.js        # 界面：渲染、点选、动画、日志、AI 回合调度
```

## AI 说明

AI 对全部局面（每排 0–7 颗，共 8³ = 512 个状态）用动态规划预计算胜负表，
走子时选择一手把对手送入必败局面的走法；若当前已处于必败局面则拿 1 颗尽量拖延。

比简单的「异或归零」更准确：misère 规则下存在临界局面（如只剩 `[0,1,2]` 时），
直接走异或归零会把「偶数个单骰堆」送给对手导致落败，DP 解天然规避了这类陷阱。
