# 357 微信小游戏首版

## 范围与发布边界

- 在 GitHub `357-game` 维护微信小游戏端。基线 `f10caa667a76ad9618bbff14e1d7f2672efc1f39`。
- 原有网页与 Android 1.0.1 不更改，不升 APK 版本，不发布安卓更新。
- 微信端采用 Canvas 2D + CommonJS，未使用 DOM、React CDN、WebView、远程脚本或第三方 SDK。
- 首版：同屏双人、三档人机、电脑先手、提示、教学/记录、六个本地绘制头像、音效/震动开关、本地战绩/存档和可选分享。
- 双人指同一设备轮流玩，不是远程好友对战。分享仅分享小游戏入口，不代表建立联机房间。
- 不接入广告、支付、云排行、用户微信头像或自有账号系统。业务代码不进行网络请求；首次获取代码包仍依赖微信和网络，首次下载与平台服务不属于“离线可玩”承诺。
- `minigame/core/engine.js` 是平台无关规则/AI模块。为避免改变已发布安卓版本，本次尚未把旧网页/安卓切到新引擎；后续切换必须单独回归和发版，而不是声称三端已经自动同步。

## 导入微信开发者工具

1. 使用官方微信开发者工具，导入**仓库根目录**；配置 `compileType: game`、代码根 `minigame/`。Mac RC 2.02.2607271 实测原 `minigame` 配置导致 `game.js 未找到`；切为 `game` 并重开项目后 CLI preview 编译通过。搜索文档中的枚举不能替代安装版本验证。
2. 仓库 `project.config.json` 使用明确的占位 `touristappid`，不是有效测试号。测试时可使用微信官方分配的**小游戏测试号 AppID**，支持开发和预览；不能用它上传正式发布或验证商业化能力。正式发布仍需正式账号和相应资质。
3. 本地填写真实 AppID；勿把上传私钥、开发者凭据、账号信息写入源码。`project.private.config.json` 已忽略，具体覆盖能力以开发者工具当前版本为准。
4. 编译后查看首页和控制台。仅有 Node 测试或浏览器 Canvas 截图不代表微信运行成功。
5. 管理员在后台添加开发者/体验成员后，生成预览二维码；在 iOS、Android 微信分别实测。
6. 完成下方清单且确认主体、资质、隐私等后，才上传体验版/提审。当前未提供正式 AppID，不宣称已上传或上线。

## 技术结构

- `minigame/game.js`：微信入口。
- `minigame/platform.js`：Canvas/DPR/安全区、生命周期、触摸、微信存储、音效、震动、可选分享。
- `minigame/ui.js`：Canvas绘制、交互、回合时序、首页/规则/教学/对局/结算。
- `minigame/core/engine.js`：不可变落子、精确反常Nim求解、三档AI、存档重放校验。
- `minigame/assets/tap.wav`：自制波形短音，`scripts/generate-minigame-audio.py` 可重建。
- `tests/`：无网络自动化测试。新代码与旧三项测试都必须运行。
- `scripts/preview-minigame.js`：本地开发Canvas预览，不是微信模拟器，输出在忽略的 `artifacts/`。

## 规则与难度

3、5、7三排；每回合只取一排且至少一颗；拿到最后一颗的人输。骰面点数仅为视觉表现，不影响数量或胜负。

- 休闲：随机合法安全走法（有其他选项时避免立即取光）。
- 挑战：70%调用精确策略，其余使用休闲策略；随机分支也可能恰好是最优步，因此不能解读为固定70%正确率。
- 高手：有必胜步时必选；必败局面不保证胜利，不宣传“电脑永远赢”。
- 使用提示的对局属于辅助练习，不应伪装为无辅助战绩。

## 必须完成的微信真机验收

- [ ] 真实小游戏 AppID 下编译成功，无控制台异常；分享按钮按平台实际能力工作。
- [ ] iOS/Android：窄屏、全面屏，胶囊/刘海/底部安全区不挡按钮；三排骰子不折行。
- [ ] 双人轮流、三档AI、电脑先手、取消/确认、提示、全部取完判负。
- [ ] 六个头像、声音/震动开关、系统静音策略、设置重启保持。
- [ ] 连点确认、动画/AI期间返回和重开，不重复落子、不串局。
- [ ] 微信切后台/锁屏/回来，电脑不多下一步；退出重进可继续；损坏存档安全放弃。
- [ ] 终局战绩仅计一次，提示辅助标记正确；本地数据清除行为与说明一致。
- [ ] 包已下载后关闭网络可继续本地对局；分享失败不影响继续玩。
- [ ] 教学/走子记录不溢出；弹层关闭可返回正确状态。

## 资质与隐私待核

这是实际对局游戏，按微信小游戏真实类目申报，不能以“益智工具”绕过游戏要求。
管理员须在当期后台核实主体准入、备案/版号适用要求、实名/防沉迷接入、内容及隐私声明；免费、无广告、单机不自动等于豁免。
不把前期关于包体、游客调试等推测视为准入结论。平台要求未落实时，不承诺公开发布日期。

业务本地数据：难度/声音/震动/头像设置、当前棋局及走子记录、战绩。业务代码不上传它们，不采集手机号、位置、通讯录、微信头像。微信平台本身的数据处理以其政策为准。正式隐私声明需由主体确认，并与最终实际代码、平台SDK保持一致。

内容：中性策略游戏文案，无下注、现金/实物兑奖、充值筹码或饮酒惩罚。分享自愿，不以分享解锁游戏或奖励。图形头像和短音为程序生成；系统字体，不外带未授权字体。
